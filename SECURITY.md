# Security Policy

## Supported Versions

The following versions of PheonixVirtualizer are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of PheonixVirtualizer seriously. If you find a security vulnerability, please do not open a public issue. Instead, please report it privately.

### Process
1.  **Email:** Please send an email to [fallofpheonix@example.com] (placeholder).
2.  **Details:** Include a detailed description of the vulnerability, steps to reproduce, and potential impact.
3.  **Timeline:** We will acknowledge receipt of your report within 48 hours and provide a timeline for resolution.

### Disclaimer
PheonixVirtualizer performs static analysis on local source code. It does not execute your code. However, it does use third-party parsers (Tree-sitter) and AI APIs (Gemini). Ensure your API keys are kept secure and never committed to version control.
